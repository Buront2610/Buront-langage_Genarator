# 2026-09-21 生成文体の修正

## 再現した問題

画面の「全文を変換 / 展開を許す / 既知表現も許可 / 標準 / 全系列」で、
`田中がAを復旧した。Bは停止中で、私は明日確認する。` を生成すると、
原文の報告書形式の整理と無関係な語録の引用しか出なかった。
canonical を「既知表現を許容する」ではなく「引用だけ生成する」と実装していた。
invent の中心句も「〜に見立てる」「〜に採点権がある」という説明文に偏っていた。
既存の事実保持・APIテストはこの文体の欠落を検出していなかった。

## 修正

- 新規性の全設定で、対応する意味関係があれば創作計画を生成する。
  語録引用は対応する創作計画がない場合の、出典を明記した代替に限定。
- 援助・寒さ・復旧・停止・確認の比較と帰結を、断定、尺度の取り違えへの反論、
  擬人化、評価の逆転を含む口語へ変更した。既存句の貼り付けだけにはしない。
- 出力の役割・状態・対象概念・帰結を独立した逆解析器で検査する構造は維持。
  原文の否定、主体、予定、数量を変更しない。
- 完結した疑問や断定に「という話」を重ねない。疑問符の後の句点も除く。
- 検索索引をワーカーの起動時に用意し、準備完了後に生成要求を受け付ける。
  生成自体の制限時間とキャンセル機構は維持する。

## 検証の範囲

新規性3設定、意味関係4種類、無関係な決め台詞だけの偽候補、語尾の重複を
`test/v1/style-regressions.test.js` に追加。既存の役割・否定・時制の改変テスト、
辞書・再解析・系列・再現・APIも検証する。実行ログは `artifacts/style-*.log`。
これらは構造・回帰の検査であり、人間による文体評価の代替ではない。

任意の日本語に対応した自由生成ではない。意味関係の対応範囲は依然として限定され、
S/Qは未学習。今回、これらの制約を解消したとは扱わない。
