# 生成処理・文体ベクトル監査（2026-09-21）

追記：利用者から比較案自体が評価に値しないとの指摘を受け、人間チェックをいったん取り下げた。個別の評点へは変換していない。原文を再読した訂正内容は `original-log-reread-20260921.md` を参照。以下は取り下げ前の測定記録として保持する。

## 結論

現実装を「ブロント語らしさが検証済み」とは判定できない。機能テストの合格は文体の合格ではない。語り口 S・魅力 Q は未学習であり、今回も人間の評点を捏造・補完していない。

設計書の文体・評価要件（`design/統合詳細設計書_v1.0.md` の語形・構文・概念接続・論理展開・発話行為、S/Q/C の盲検比較）を基準に、生成から候補選択まで追跡し、実際の解析・生成・再解析を通した12入力を測定した。

## 生成処理の問題

- `packages/core/rhetoric.ts` の対応関係は援助・寒さ・復旧・停止・確認の5系統に限られる。新しい話題を一般的に文体変換する能力はない。
- 原文の事実節を主に保存し、有限の比喩・結論を追加する構成。24候補で結論は15種類、うち9種類が2回ずつ出現した。概念接続や論理展開が入力ごとに十分生成されているとは言えない。
- 原文に対し、変更せず残した事実節の文字数比の平均は0.966。生成文全体の97%が原文という意味ではない。全文の文字数は入力の平均10.66倍で、短文への付け足しが大きい（短い入力の影響が強い指標）。
- 12入力中8入力で各3候補、残り4入力は `unsupported_relation`。雨、会議疲れ、見直しによる提出遅れ、伝聞が対象外だった。失敗を除外して評価してはいけない。
- `packages/core/output-features.ts` の既存特徴は44次元（表層指標12＋文字種二連のハッシュ32）。意味埋め込みや学習済み文体判定器ではない。候補選択でも S/Q が null のため、文体の学習点で選別していない。
- 旧 `lib/vector-space.js` の TF-IDF 検索・系列ベクトルの存在は、新しい構造生成器の文体品質を保証しない。

## ベクトル測定

文字2〜4連の明示的 TF-IDF 語彙を原文ログだけで作り、L2正規化した文と参照重心のコサイン類似度を測定。参照はスレッド単位で514件の構築用と178件の保留用に分割し、近似重複8件を除外。分割・語彙は生成前に固定した。

|条件|原文ログ保留分|生成全文|普通の説明文|意味不整合の対照文|
|---|---:|---:|---:|---:|
|元の文字列|0.1169|0.1933|0.2045|0.1831|
|漢字・カタカナ・英数字を伏せる|0.1740|0.3087|0.3009|0.3000|
|上記＋既知の決まり文句を除去|0.1739|0.3103|0.3009|0.2999|

普通の説明文が生成文以上、意味不整合の対照文も近い値を取る。したがって「類似度が高いからブロント語」という判定は不成立。原文ログ保留分も低く、参照と対照の識別力は条件によって逆転する。生成候補に有利な閾値を設定したり、この値を S として投入したりしていない。

限界：これは意味埋め込みではない。文字種マスクではひらがなの内容語が残る。長さや頻出構文の影響を分離できていない。原文ログの出典はすべての文の文体・品質の正解ラベルではない。対照文も人手採点済みの負例ではない。ベクトル側の保留分があっても、生成器は全コーパスを参照するため、未知スレッドへの生成汎化試験ではない。

## 人間チェック

`http://127.0.0.1:4173/#review` に14組を用意。12入力すべて（生成失敗を含む）＋左右反転した再提示2組。候補は点数で選ばず順番で選び、原文・決まり文句の付加・普通の説明・別のネット口調・意味不整合の対照と比較する。方式・点数・順位は全件回答するまで表示しない。

S＝語り口、Q＝魅力、C＝原文との整合性を独立に回答。左／右／同程度／両方だめ／判断できないを選択できる。初期値は空。3項目を明示的に選んで保存したときだけ、`.runtime/reviews/<batchId>.json` に記録する。保存済み回答は再起動後も継続できる。全件回答しても自動学習・自動合格にはしない。これは単一評価者による pilot であり、一般的な文体評価器の検証用ラベルとは扱わない。
