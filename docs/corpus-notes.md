# ログ分析メモ

提供されたログは約87万バイトで、掲示板の見出し、投稿情報、本文が混在していました。変換規則には本文中で繰り返し確認できた次の特徴を採用しています。

## 表記

- 全角と半角カナの混在
- 「あまりにも」から「あもりにも」などの特徴的な誤記
- 「ということ」から「と言う事」への表記変化

## 構文

- 「致命的な致命傷」のような同義語の反復
- 「一番最強」のような比較級と最上級の重複
- 「確定的に明らか」のような断定の重ね掛け
- 「稀によく」のような意図的に矛盾した頻度表現

## 語り口

- 自分を「一級」、相手を「一般人」や「雑魚」と位置付ける
- 「やはり」「しかも」「さらに」で主張を連結する
- ゲーム内の強さと現実の評価を同じ軸で語る
- 結論を「真実」「明らか」「決まった」と強く断定する

変換機では意味の破壊を避けるため、攻撃的な定型句は「有頂天」レベルに寄せています。
