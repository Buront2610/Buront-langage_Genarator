## 再現できる変更

- 「田中が佐藤を助けた。」と「佐藤が田中を助けた。」は、創作部9案の同一文が0件。過去否定、過去継続、予定にも正負例を追加した。
- 「今日は寒い。」に「寒さ=冷え込み」: 通常3案。「寒さ=冷気」: 要確認3案。事実の文を挿入する置換: 通常・要確認とも0案、理由はdictionary_rejected。
- 原文が「田中が佐藤を助けた。」なのに「実際には佐藤が田中を助けた。」を修辞へ混入し、生成側のcoreTextと許可集合まで更新する試験は棄却。
- 「田中が確認しなかった。今日は寒い。」→「田中が確認しない。今日は寒い。」は、後半のunknownにかかわらずS-temporalがfail。
- 「田中がAを復旧した。Bは停止中で、私は明日確認する。」は、成果・残件・予定の3単位。fullの安全な独立節は「Bは停止中だ。」として別節にでき、原文と出力の再解析も照合する。
- 旧方式/新方式/普通文/通常の冗談/意味不明の対照を63ペア出力。左右とも同じ44特徴。これを好みの精度や品質合格とは呼ばない。
