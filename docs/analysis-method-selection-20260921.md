# 分析手法の選択と適性検査

ユーザーの指定は「分析手法はなんでもいい、適したものを使う」。コサイン・PCA・クラスタリングに限定しない。調べたい性質を指標が実際に捉えるか、先に確かめる。

今回、原文の同じ投稿に対して条件だけを変える比較を追加した。全文解析済みの完全重複除外後2,363投稿を参照し、非空行が3行以上で、操作によって本文が変わる全投稿を対象とした。検査用の変更は生成候補ではなく、人間評価の回答にも入れていない。

| 検査用の操作 | 比較件数 | 原文重心へのコサインの平均変化 | 33特徴すべて不変 |
|---|---:|---:|---:|
| 行の順序を逆転 | 1,330 | +0.000259 | 1,315件（98.9%） |
| 改行を空白に置換 | 1,330 | −0.009213 | 0件 |
| 各行末に句点を補う | 1,314 | −0.004506 | 0件 |

行順を逆にしたとき、コサインの絶対変化が0.01未満の投稿は98.0%。33特徴の多くは数や比率なので、順序を変えても同じ値になる。特徴が完全に同じなら、それを入力とするPCAやクラスタリングでも、その順序の違いは検出できない。

これは「行を並べ替えたら必ず悪文になる」という評価ではない。文章の前後関係が変わっても検出できないことを示す適性検査であり、自然さの正解率ではない。

## 採用する用途

- 句読点・改行の偏り: 全数集計、原文の長さ・引用を分けた比較、同じ本文を使った条件比較。
- 語彙・表記の類似: 文字列コサインと最近傍原文。自然さ・意味の合格点にはしない。
- 原文の混在: PCA・クラスタリングで群の違いを調べ、代表原文に戻る。作者や真贋の判定にはしない。
- 語尾と後続節: 原文用例の前後を照合し、後続説明・対比・疑問・引用などの関係を区別する。単純な部分文字列検索と語尾の認定を混同しない。
- 出来事の順序・因果・意味保持: 入力と出力の意味関係を直接照合する。形態素・係り受け解析を導入する場合も、崩した表記に対する誤解析を原文で点検する。
- 最終的なブロント語としての自然さ: 機械検査と分け、ユーザーの人間評価で判断する。

閲覧用: [条件比較レポート](http://127.0.0.1:4174/method-validation.html)

実行スクリプトは `scripts/validate-style-methods.py`。参照する元スクリプト・投稿データ・語彙をハッシュで照合し、変更の操作が文字や行の内容を意図せず変えていないことを各比較で検査した。全3,974比較の結果は `artifacts/fulltext-analysis-20260921/method-validation-pairs.csv`、集計は同ディレクトリの `method-validation.json` に保存。

全文解析の再実行はしていない。同じハッシュと同じ投稿選択を確認したうえで、今回追加した条件比較のみを実行した。
