# 語彙変換の使用例と発祥を区別する監査

## 結論

現行の本文変換は、収録ログの一文に変換先があることを採用条件にしていた。これは使用例の照合であり、その語がブロントさんから生まれたことや、他の話者と区別できることの検証ではない。「雰囲気→ふいんき」「全員→ぜいいん」の自動置換は停止した。入力・引用・原資料に元からある表記は保持する。

「ふいんき」については、飯間浩明による解説に1986年の地域分布の報告が紹介されており、ブロント語発祥とする説明は成り立たない。[飯間浩明「ふいんき」「サザンカ」](https://kangaeruhito.jp/article/3565)。「ぜいいん」は一般的な口語の読みと区別する根拠がこのプロジェクトにはなく、ログ内での使用だけを理由に新しく挿入しない。両者の歴史的初出を今回特定したわけではない。

## 全24件の固定語彙・句変換の棚卸し

以下の「使用例あり」は収録ログとの完全一致で確認したことだけを指す。**発祥確認済みの規則は0件**。継続する変換も、ブロント語固有という認定ではなく、収録された言い回しの応用である。出典IDと引用文は `artifacts/lexical-origin-audit-20260922/rules.json` に保存した。

## 実行経路と再混入の防止

- 起動中アプリは `server.js` → `dist/apps/server/index.js` → 現行コアの `makeRewritePlans` を使う。旧 `lib/corpus-engine.js` 等にも一般的な読みの変換は残るが、この起動経路では使われていない。旧エンジンまで修正・検証済みとはしない。
- 停止した2規則は候補生成と独立検証の両方の許可集合から外した。本物の原文出典を付け直しても、その編集は承認されない。
- 宣言を残したのは監査記録と既存の句読点規則IDを維持するため。句読点の出典として文を読むことと、その中の全単語を変換対象にすることは別。
- UIの変更箇所に「出典は収録ログでの使用例」であり、発祥・固有性を示さないことを明記した。
- 文体ベクトルの類似度も発祥の証明には使わない。現行の文体指標にこの2語を直接加点する規則はなかった。

## 検査

強度1〜3で「全員」「雰囲気」を保存し、入力に元からある「ぜいいん」「ふいんき」は保存する検査と、停止規則を本物の出典付きで再投入しても独立検証が拒否する検査を追加。句読点の前回テストにあった、これらの置換を必須とする期待値も修正した。結果・ビルド・稼働確認は同名の artifacts ディレクトリに記録する。
