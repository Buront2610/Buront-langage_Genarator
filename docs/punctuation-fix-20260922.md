# 生成本文の句読点修正

全文解析の結果が生成処理に反映されていなかったため、本文の編集規則と独立した検証処理に句読点の変更を実装した。

- 引用・括弧の外にある単独の「。」は、後続本文があれば改行に変換する。投稿末尾や、すでに改行がある位置では句点だけを削除する。
- 既存の改行・段落区切りは保持し、句点を外すことで別々の文がくっつくのを防ぐ。
- 助詞・接続表現の直後にある任意の読点だけを除く。名詞の列挙などの読点は残す。
- 引用、入れ子の引用、閉じていない引用、括弧内では句読点・語尾・語句を変更しない。数値、URL、疑問符、感嘆符もこの句読点変換の対象外。
- 説明の後続節がない文末に「んだが」を自動追加する規則を削除し、丁寧形から普通形への限定変換に置き換えた。
- 「本文の変更箇所」には、空白の矢印ではなく「改行」「削除」と表示する。

句読点変更も編集履歴に含め、入力の範囲、変更規則、適用条件、出典を再検証する。生成後の文字列だけを無条件に置換する処理ではない。

- `packages/core/rewrite.ts`
- `packages/core/rewrite-validation.ts`
- `apps/web/src/main.tsx`

回帰検査: `test/v1/punctuation-regressions.test.js`。通常文、複数文、既存改行・段落、引用、括弧、数値、URL、疑問、列挙、閉じていない引用、編集履歴の改ざんを確認する。生成例・実行ログは `artifacts/punctuation-fix-20260922/` に保存する。

2026-09-21の全文解析レポートにある75生成例は修正前の記録。この修正の検証結果とは区別する。句読点修正で生成全体の自然さまで合格したとは判定せず、人間評価の回答も自動入力しない。
